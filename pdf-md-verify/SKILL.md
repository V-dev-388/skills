# PDF 与 MD 文档核对（PDF-MD Verify）

## Overview

核对一个 PDF 与一个 Markdown 文件的文字内容是否一致，输出逐项核对结论。若 PDF 是扫描版（无文本层），先按 scan-pdf-to-text 的流程识别文字，再与 MD 对比。重点核对正文、标题、页码标注、脚注四类内容。

> 以下命令在 skill 根目录（SKILL.md 所在目录）下执行；`scan-pdf-to-text` 需与本 skill 位于同一父目录（本仓库内即如此），脚本位于其 `scripts/` 子目录。

**工具优先级（硬约束）**：`agent 内置工具 > macOS 原生工具 > 第三方库`

- 识别图片一律用 agent 内置多模态读取工具（Read / file_view），不做主力 OCR 调 macOS 原生框架。
- 图像处理（渲染、裁剪）用 macOS 原生工具（复用 scan-pdf-to-text 的 Swift 脚本）。
- 不装第三方 PDF/OCR 库。

## 工作流

### 步骤 1：确定 PDF 是否有文本层

编译并运行 scan-pdf-to-text 自带的检测脚本：

```bash
cd ../scan-pdf-to-text/scripts && swiftc -O pdf_text_layer.swift -o pdf_text_layer
./pdf_text_layer <待核对.pdf>
```

- `HAS_TEXT_LAYER` → 直接用提取文本作为 PDF 侧基准（注意提取乱码时仍按扫描版处理）。
- `NO_TEXT_LAYER` → 扫描版，执行步骤 2。

### 步骤 2：扫描版识别（仅扫描版需要）

1. 渲染 JPG：`render_pdf_pages <pdf> <outdir> [scale] [quality]`（脚本在 scan-pdf-to-text/scripts/，见该 skill 步骤 2）。
2. 用 Read 工具逐页识别，逐页记录：正文文字、原书页码（如 `(448)`）、脚注编号与内容。
3. 整页识别不清的区域，用 scan-pdf-to-text 步骤 3.5 的 `crop_region` 裁剪局部放大识别，不反复整页重试。

### 步骤 3：读取 MD 基准

完整读取待核对的 `.md` 文件。注意 MD 可能含：
- 文件头部说明（如"清洗后文档，已剔除页眉"）——这部分不参与正文核对；
- 正文段落；
- 文末集中注释（中译注等），编号 ①②③… 与正文脚注编号对应。

### 步骤 4：逐项对比

按以下四类逐项对比，对照时以原书页码（PDF 侧边标注）为锚：

1. **标题/章节标题**：标题文字、编号、年份括号是否一致。
2. **正文段落**：逐段比对，重点看段首句、段尾句、专名音译（如人名地名）、数字与年代、括号内原文词。忽略 MD 排版差异（空行、缩进、粗体标记）。
3. **页码标注**：PDF 原书页码在 MD 中的插入位置和数值是否对应。
4. **脚注/注释**：编号数量、内容是否一一对应（含"非本书页码"这类说明）。

### 步骤 4.5：差异复核（局部裁剪精识别）

识别文字与 MD 出现疑似差异时，先复核再下结论，避免把识别误差误判为真实差异：

1. 根据疑似差异所在的页码，定位到对应整页图，先整体浏览确认差异文字在该页的大致位置（按视觉位置描述，如"中上段第三行"）。
2. 用 `crop_region` 裁剪该区域放大（推荐比例模式，如 `--ratio 0.2 0.3 0.6 0.4 3.0`），只 Read 局部图做精识别。
3. 判定：
   - 局部精识别与 MD 一致 → 原差异为识别误差，修正识别基准，不列入差异清单（可在报告中备注"初判差异经局部复核为识别误差"）；
   - 局部精识别与 MD 仍不同 → 确认为真实差异，按步骤 5 列入差异清单。
4. 复核依赖多模态视觉能力；若会话模型不支持图像输入，不要强行目测下结论，标注 `[待核 — 需视觉复核]`。

### 步骤 5：输出核对报告

报告格式：

- **总体结论**：完全一致 / 存在差异（差异数）。
- **核对范围**：PDF 页数、原书页码区间、MD 行数。
- **差异清单**：每条列出 位置（原书页码或 MD 行号）→ PDF 侧文字 → MD 侧文字 → 差异类型（文字/页码/注释/排版）。
- **非内容性差异**：如 PDF 上的高亮、批注、扫描噪点，说明不影响文字一致性。

## 注意事项

- 识别出的文字与 MD 个别字词的差异（如"翻谱"vs"翻译"）需如实列出，由用户判断是否为转录笔误，不要自行判定"应为某某"。
- 无法确认逐字一致时标注 `[待核]`，不得默认一致。
- 结论要可复核：给出来源页/行号，不笼统说"大致相同"。
